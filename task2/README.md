# Задание 2 — маска «Этот человек»

Откройте [веб-страницу задания](https://boorudborne-cell.github.io/model-viewer-ar-demo/task2/) на телефоне по HTTPS. Работа с монетой остаётся на главной странице репозитория.

## Два режима

1. **Примерить маску** (`face.html`) — MindAR Face Tracking крепит GLB-маску к носу обнаруженного лица (`mindar-face-target`, `anchorIndex: 1`). По умолчанию открывается фронтальная камера; кнопка «Сменить камеру» позволяет навести заднюю камеру на другого человека.
2. **Оживить плакат** (`marker.html`) — MindAR Image Tracking ищет `assets/marker.png` по заранее скомпилированному файлу `targets.mind` (`mindar-image-target`, `targetIndex: 0`). При распознавании поверх портрета появляется та же GLB-маска. Покажите маркер с другого экрана или распечатайте его.

Изображение-маркер — присланный пользователем плакат. Файл `targets.mind` создан из него [официальным компилятором MindAR](https://hiukim.github.io/mind-ar-js-doc/tools/compile/). Криволинейная glTF-маска в `assets/this-man-mask.glb` собрана скриптом `build-mask.py` из прозрачного изображения лица `assets/this-man-face.png`. Изображение лица создано с помощью ImageGen по присланному плакату: выделено лицо, удалены надписи и фон с сохранением узнаваемого чёрно-белого образа.

Обе страницы используют локальные копии A-Frame 1.5.0 и MindAR 1.2.5, имеют окружающее и направленное освещение и запрашивают камеру только после нажатия «Включить камеру». Для работы камеры требуется HTTPS или localhost, а также разрешение браузера. Для режима маркера нужны хорошее освещение и видимый целиком плакат.

На `preview.html` модель можно осмотреть без камеры.

## Локальная проверка

Из корня репозитория запустите `serve.bat`, затем откройте http://localhost:8080/task2/. Для обновления GLB после изменения прозрачного изображения лица запустите `python task2/build-mask.py`.

Документация: [Image Tracking](https://hiukim.github.io/mind-ar-js-doc/quick-start/overview), [Face Tracking](https://hiukim.github.io/mind-ar-js-doc/face-tracking-quick-start/overview).
